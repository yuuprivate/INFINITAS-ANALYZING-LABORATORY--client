## 機能
 INFINITASのプレイリザルト・スコアの自動取得とサーバーへの送信
 サーバーエンドポイント変更時の自動追従・URL再取得機能
 `config.txt` の自動更新

## 導入・使用方法
1. 最新のリリース（Releases）からZIPファイルをダウンロードし、任意のフォルダに展開します。
2. フォルダ内にある `config.txt` を必要に応じて編集します。（初回通信時に最新のサーバーURLが自動取得されるため、基本的にはそのままで構いません）。
3. beatmania IIDX INFINITAS を起動します。
4. 本ツールの `[実行ファイル名].exe` を起動します。
5. コンソール画面（黒い画面）が表示され、`HTTP POST 成功 [Status: 200]` などのログが出れば通信準備は完了です。そのままゲームをプレイしてください。

## config.txt について
実行ファイルと同じ階層にある `config.txt` は、送信先のサーバーURLを管理しています。

API_ENDPOINT=[https://xxxxxxxxx.trycloudflare.com](https://xxxxxxxxx.trycloudflare.com)
GIST_FALLBACK_URL=[https://gist.githubusercontent.com/.../raw/url.txt](https://gist.githubusercontent.com/.../raw/url.txt)
